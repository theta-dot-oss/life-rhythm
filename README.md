# だいちゃーじ！生活リズム

研究・休憩・運動のリズムを、青いペンギンが「次にやること」として案内してくれる常駐アプリです。
自分で時計を見たり、次の行動を判断したりしなくてよいようにします。

- 公開URL: https://theta-dot-oss.github.io/life-rhythm/
- 1枚のHTMLだけで動きます。インストール不要、Edge / Chrome で開くだけ。
- 設定の変更はチャットで Claude に伝えます（`config.json` を書き換えて反映）。

## 使い方（Windows）

1. Edge か Chrome で上のURLを開く。
2. 「通知を許可」をクリックして、ブラウザの通知を許可する（はじめの1回だけ）。
   - Windows 側で通知が出ない場合：設定 → システム → 通知 で Edge/Chrome がオンか、集中モードがオフかを確認。
3. 右上の **⧉** を押すと、常に最前面の小窓（ピクチャインピクチャ）になります。
   ドラッグで好きな場所へ移動、角をつかめばサイズ変更できます。元のタブは閉じずに最小化してください。
4. 毎日のはじめに **［研究開始］**、終わるときにメニュー（⋯）か 21:00 以降に出る **［研究終了］** を押します。

### アプリとしてインストール（おすすめ）

Edge のアドレスバー右の「アプリをインストール」アイコン、または ⋯ → アプリ → 「このサイトをアプリとしてインストール」。
タスクバーにピン留めすると、ふつうのアプリのようにワンクリックで起動できます。
`edge://apps` でアプリを右クリック → 「ログイン時に起動」をオンにすると、PC起動時に自動で立ち上がります。

### ボタンは状況に応じて切り替わります

| 状態 | 表示されるボタン |
|---|---|
| 待機中 | 研究開始 |
| 研究中 | 休憩開始（50分たつと「10分延長」も出る） |
| 休憩中 | 作業再開 |
| 17:15（運動の枠） | 運動開始（最優先で表示） |
| 運動中 | 運動終了 |
| 21:00 以降 | 研究終了（まとめが出る） |

延長・一時停止・今日の運動をなしにする・通知を30分ミュート・テーマ切替などは右上の ⋯ メニューにあります。
守れなかった予定を責めたり、未達成を積み上げたりはしません。その時点から次の行動を案内します。

## 1日の流れ（平日の初期設定）

| 時刻 | 行動 |
|---|---|
| 10:00 | 研究開始（50分作業・5分休憩のくり返し） |
| 14:00 | 昼食・自由時間（［休憩開始］を押すと長い休憩になる） |
| 15:00 | 昼寝・休息 |
| 17:00 | 起床・水分補給・準備 |
| **17:15** | **運動（曜日別メニュー・固定）** |
| 17:40 | 研究再開 |
| 21:00 | 研究終了・夕食準備 |
| 21:30 / 23:30 | 夕食 / 入浴（表示のみ） |

運動メニュー：月 リングフィット下半身・体幹 / 火 アイソレーション・柔軟 / 水 フィットボクシング / 木 リングフィット全身 / 金 ヨガ・ストレッチポール / 土 ウォーキング30〜60分 / 日 休養。

## 設定を変えたいとき

チャットで「作業時間を45分にして」「金曜の運動をピラティスにして」「21:00の終了を21:30に」などと伝えてください。
Claude が `config.json` を書き換えて push すると、アプリは10分以内（または開き直し）に反映します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML / CSS / JS を1枚に） |
| `config.json` | 時間割・運動メニュー・タイマー設定・ペンギンのセリフ・休憩の提案 |
| `data/today.json` | その日のタスクとカレンダー予定。毎朝 Claude が書き込む |
| `sw.js` | 通知にボタン（休憩開始 / 10分延長 など）を付けるためだけのサービスワーカー。キャッシュはしない |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | アプリとしてインストールするための情報とアイコン |
| `tools/validate.py` | `config.json` と `data/today.json` の形式チェック |
| `.github/workflows/pages.yml` | main に push されたら GitHub Pages に公開 |

### `data/today.json` の形式

```json
{
  "date": "2026-11-02",
  "generated_at": "2026-11-02T07:40:00+09:00",
  "focus": "今日いちばん大事なこと（1行）",
  "tasks": ["タスク1", "タスク2", "タスク3"],
  "events": [
    { "start": "2026-11-02T13:00:00+09:00", "end": "2026-11-02T13:30:00+09:00", "title": "うちあわせ" }
  ]
}
```

- `date` が今日と違うときは「今日のデータは未更新」と表示するだけで、古い内容は出しません。
- 予定の件名に人名・団体名・場所・URL・メールアドレスが含まれる場合は、一般名詞だけにぼかして書き込みます（公開リポジトリのため）。
- 3時間以内の予定が運動の枠（17:15〜）と重なるときは、運動の呼びかけをその予定の後にずらします。長い予定（RA など）はずらしの対象にしません。

## 記録について

作業時間・サイクル数・運動の実施は、その日の「まとめ」に表示し、ブラウザの中（localStorage）に直近60日分だけ残します。
リポジトリには書き込みません。
